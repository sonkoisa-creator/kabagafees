📱 Install as an App (PWA)
This system can install like a normal app on Android phones, tablets, laptops and desktops — no Play Store needed. One requirement: it must be opened from a web address (http:// or https://), not by double-clicking the HTML file. If you're seeing this page by double-clicking the file, installation isn't available yet.
  1. Put this HTML file, manifest.json, service-worker.js, and the two icon files in one folder.
  2. Host that folder somewhere reachable by browser — a free static host (e.g. Netlify/GitHub Pages), a school server, or even a laptop running python3 -m http.server on the school Wi-Fi.
  3. Open that web address in Chrome/Edge on the device you want to install on, then use the browser's "Install app" / "Add to Home Screen" option.
  4. Once installed, it opens like any other app and keeps working offline — your data stays on that device either way.
🏫 Academic Year & Term Setup
Kabaga Junior School runs on three terms per academic year. Pupils, balances, bursaries and boarding status all carry forward automatically when you move from one term to the next — nobody needs to be re-registered.

📶 Sync & Offline Status
This app works fully offline — every screen above keeps working with no internet connection, and all data is saved on this device. Cross-device sync needs a small server to push and pull changes; until one is connected here, every device keeps its own independent copy of the data.
🗄️ Automatic Local Backups Director — restore any date
A snapshot of the whole system is saved automatically, once per day, in this browser's storage (separate from your normal data). Use this to roll back to an earlier date if something gets entered wrong — it does not affect the manual .json/.csv downloads under the Backup tab.
💾 Backup Your Data

All pupil records, payments, bursaries, arrears, fee settings, expenditure, director contributions, and uniform inventory/sales are saved automatically on this computer. Download a backup file regularly and store it safely (e.g. on a USB drive or email it to yourself) in case this device is lost, reset, or the browser data is cleared.

The .json backup is the one to use with "Restore Data" below — keep it safe. The .csv summary opens directly in Excel or Google Sheets so you (or anyone else) can read every pupil's fees, boarding status, payments, arrears, and bursary at a glance — handy for sharing with the Director or printing for a file.
